# English Lab · 我的英语学习库

线上地址：https://lxy-187.github.io/English/

一个零依赖、零构建的静态网页。**直接双击 `index.html` 就能用**，也可以放到任何静态托管上（GitHub Pages / Vercel / 自己的 NAS）。

数据和界面完全分离 —— 你平时只需要编辑 `data/` 里的四个文件，界面会自动更新，不用碰任何代码。

---

## 板块结构

| 板块 | 路由 | 文件 | 内容 |
|---|---|---|---|
| 概览 | `#/home` | — | 统计、今日三则（每天自动轮换）、最近加入 |
| **单词剖析** | `#/words` | `data/words.js` | **核心图景 → 多维义项 → 构词与边界**，全部带双向链接 |
| 词根词缀 | `#/roots` | `data/roots.js` | **每层含义自成一节**，派生词挂在它所属的那层下面 |
| 关键辨析 | `#/contrasts` | `data/contrasts.js` | 卡片墙 → 点进独立页面：一句话区分 + 逐词拆解 + 易错点 + 自测 |
| 好词好句 | `#/phrases` | `data/phrases.js` | 句式、搭配、替换、用法、金句，按主题分类平铺 |
| 范文解析 | `#/essays` | `data/essays.js` | 以**考研真题**为主，按年份／考试／题型／主题分类；点进去看提纲 + 逐句批注 |
| 我的收藏 | `#/starred` | localStorage | 任意条目点星号即可收藏 |

**导航模型**：词根、辨析、范文都是「卡片墙 → 独立页面」。列表页只放卡片，一屏能扫完；点进去是一个只有这一个条目的干净空间（阅读栏宽 820px），左上角返回。不做左右分栏，避免列表和内容互相干扰。

**视觉材质**：玻璃质感（类 iOS 的分层半透明），分三层——

| 层 | 元素 | 做法 |
|---|---|---|
| ① 环境层 | `body::before` | 固定的柔和光晕（靛／蓝／紫三团低透明度渐变），玻璃透出的颜色全来自这里 |
| ② 悬浮层 | 顶栏 · 侧栏 · 底部标签栏 · 视图面板 | 半透明 + `backdrop-filter` 模糊 22–28px + 提饱和 |
| ③ 内容层 | 卡片 | 半透明填充 + 顶部 1px 高光描边，**不加模糊**（几十张卡同时做 backdrop blur 在平板上会掉帧） |

系统开启「降低透明度」时（`prefers-reduced-transparency`）自动退回实色并关掉光晕。

**色彩系统**：全站只有**一个主题色（靛紫，关键处用渐变）**，用于选中态、强调框、批注高亮。另有**一个功能色（琥珀）**，只出现在两处：易错点的感叹号、已收藏的星号。其余全部由中性灰阶承担。正文对比度浅色 15.3、深色 16.5，均远超 AA。

构词成分不用三种色相，改用同一主题色的三档强弱：**词根＝实心填充（最强）· 前缀＝描边 · 后缀＝中性灰（最弱）**，详情页顶部带图例。

## 怎么追加内容

五个数据文件都是同一个模式：打开文件，照着已有条目再写一个，逗号别漏。保存后刷新页面即可。

### 1. 加一个单词剖析 → `data/words.js`

这个板块回答的不是「这个词翻译成什么」，而是「它描绘的是什么场景/动作/状态，为什么同一个词能长出这么多中文释义」。

```js
{
  id: "convert",
  w: "convert",
  pos: "v./n.",                  // 可省略
  core: "一句话说清它描绘的本质状态",     // 核心图景
  image: "一个具体的比喻/画面，让核心可记",  // 脑海图景
  origin: "拉丁语：com-（彻底）+ vertere（翻转）",   // 词源，可省略
  // 构词拆解。形式能对上 data/roots.js 里某个条目时，页面自动生成双向链接
  parts: [["con-", "彻底地", "prefix"], ["vert", "翻转", "root"]],
  rootRefs: ["com"],             // 也可以显式指定要关联的词根 id
  senses: [{
    dim: "物理形态与功能的底层重置",   // 这一维度叫什么
    tag: "工程",                      // 维度标签
    scene: "描绘场景：这个义项在现实中长什么样",
    feature: "状态特征（可省略）",
    zh: "转换、改造、折算",            // 对应中文释义
    ex: [{ en: "Convert USD into Euros.", zh: "把美元兑换成欧元／价值不变，但结算协议切换了。" }]
  }],
  // 边界对比。若 w 也是本库条目，自动互相链接；不是也没关系，会降级成纯文本
  contrasts: [{ w: "subvert", note: "同根 vertere：subvert 是从底部掀翻，convert 是原地变轨。" }],
  summary: "一句话带走（可省略）"
}
```

> **双向链接怎么工作**：你只需要写单向。在 `convert` 里写了 `contrasts: [{w:"subvert"}]`，`subvert` 的页面会自动出现一条「被提到 · convert」的反向链接；在 `parts` 里写了 `vert`、或在 `rootRefs` 里写了 `com`，对应词根页会自动多出一节「用到它的单词剖析」。不需要在两边各写一遍，也不会重复显示。指向尚未收录的词会降级成纯文本而不是断链，等你补上词条，链接自动接通。

> **访问栈**：顺着链接一层层跳进去时，详情页顶部会累积一条访问路径（如 `pervert › subvert › convert`）。点其中任意一层即可原路退回，该层之上的记录同时弹出。走到任何列表页则清空。路径存在 sessionStorage，刷新不丢，关掉标签页即重置。

### 2. 加一个词根 → `data/roots.js`

**结构原则：含义决定框架。** 一个词缀有几层意思，就写几节；每个派生词挂在它真正所属的那层下面。不存在固定节数——`ject` 只有 2 层，`per-` 有 5 层。

```js
{
  id: "grat",                    // 唯一 id，用作链接地址
  kind: "root",                  // root 词根 | prefix 前缀 | suffix 后缀
  form: "grat / grac",           // 显示的形式，多个变体用 / 分隔
  meaning: "感谢、令人愉快",       // 总括释义，用于卡片和搜索
  gloss: "pleasing, thankful",
  origin: "拉丁语 gratus",
  senses: [                      // ← 每一层含义一节，节数由这个词缀自己决定
    {
      meaning: "心怀感谢",         // 这一节的标题
      gloss: "thankful",          // 可省略
      note: "这一层怎么理解。只讲这一层，别把其他层的意思混进来。支持 **粗体**。",
      words: [
        {
          w: "gratitude",
          // 构词拆解：[形式, 含义, 类型]，类型必须是 prefix / root / suffix
          parts: [["grat", "感谢", "root"], ["-itude", "名词", "suffix"]],
          def: "感激",
          ex: "She expressed her gratitude to the team."   // 可省略
        }
      ]
    },
    {
      meaning: "令人愉快、讨喜",     // 第二层，词挂在自己这层下面
      note: "……",
      words: [ /* … */ ]
    }
  ],
  related: ["cred"]              // 相关词根的 id，可空数组
}
```

详情页会按这个结构渲染：顶部一条「N 层含义」总览，下面每层一个可折叠小节（带序号徽标），每层内部才是属于它的派生词。折叠状态按「这个词缀的第几层」单独记忆，不同词缀之间互不干扰。

### 3. 加一组辨析 → `data/contrasts.js`

```js
{
  id: "lay-lie",
  title: "lay / lie",
  tag: "高频易错",               // 显示在角标上的短标签，自己定
  level: "核心",                 // 核心 / 进阶，随意
  oneLiner: "一句话把区别说清楚，这句最重要。",
  items: [                       // 2–4 个词效果最好，会自动排成对比栏
    { w: "lay", pos: "v.", core: "放置（及物）", nuance: "细微差别、搭配、语气。支持 **粗体**。",
      ex: "Lay the book on the table.", exZh: "把书放在桌上。" }
  ],
  pitfalls: ["易错点，一条一句。支持 **粗体**。"],   // 可省略
  drills: [                                        // 自测题，可省略
    { q: "Please ______ the tools down.", a: "lay", why: "有宾语，用及物动词。" }
  ]
}
```

### 4. 加一条表达 → `data/phrases.js`

```js
{
  id: "p090",                    // 唯一即可，我用 p + 三位数
  cat: "让步与转折",              // 分类；写一个新的分类名，页面会自动多出一个筛选项
  type: "句式",                  // 句式 | 搭配 | 替换 | 用法 | 金句
  en: "That said, the objection deserves an answer.",
  zh: "话虽如此，这个反驳仍值得回应。",
  note: "什么时候用、为什么好、有什么坑。这一栏是这个板块的价值所在。",
  tags: ["连接词", "驳论"]        // 可省略
}
```

### 5. 加一篇范文 → `data/essays.js`

```js
{
  id: "ky2005-1",              // 唯一 id，考研真题建议用 ky<年份>-<序号>
  title: "中文标题",
  // ↓ 四个分类字段决定它在页面上怎么被筛选和分组
  exam: "考研英语一",           // 考研英语一 / 考研英语二 / 雅思 / 四六级 / 其他
  year: 2005,                  // 真题年份；不是真题写 null，会归到「非真题」组
  part: "大作文",               // 大作文 / 小作文 / Task 1 / Task 2 …
  topic: "社会",                // 社会 / 教育 / 环境 / 文化 / 科技 …
  genre: "图画作文 · 现象解释",
  level: "高分档",
  words: 180,
  prompt: "英文题目原文（图画题可写图画描述 + 写作要求）",
  outline: [{ label: "第 1 段 · 引入", purpose: "这一段要干什么" }],
  paragraphs: [{
    role: "引入段",
    text: "英文正文原文（整段）。",
    notes: [
      // ⚠️ mark 必须是 text 里【一字不差】出现的片段（含大小写和标点）
      //    页面会自动把它高亮，点击展开右边的讲解
      { mark: "英文正文原文", note: "为什么这么写好。支持 **粗体**。" }
    ],
    analysis: "整段的点评，显示在段落下方的灰框里。可省略。"
  }],
  highlights: [{ en: "可迁移的表达", zh: "中文", why: "什么场景能用上" }],   // 可省略
  takeaway: "一句话带走。"                                                  // 可省略
}
```

> **批注对不上怎么办**：如果某条 `mark` 在 `text` 里找不到，页面会静默跳过它（不会报错也不会崩）。发现某句点不开，先检查 `mark` 是不是和正文有一个字符的出入 —— 最常见的是连字符、撇号、空格数量不一致。

## 折叠与排序

**列表页**（词根词缀 / 关键辨析 / 好词好句）顶部只有一个「视图」按钮，筛选和排序都收在里面，按钮上直接显示当前状态（例如 `前缀 · 派生词量`）。点开面板连续调整不会关闭，点面板外面或按 Esc 收起。

排序方式同时决定分组方式，每组独立折叠，右侧一键全部折叠／展开。

| 板块 | 只看（筛选） | 排序 / 分组 |
|---|---|---|
| 单词剖析 | — | 字母（默认）· 义项数 · 关联 · 收藏 |
| 词根词缀 | 全部 / 词根 / 前缀 / 后缀 | 字母（默认）· 类型 · 派生词量 · 义项数 · 收藏 |
| 关键辨析 | — | 字母（默认）· 类别 · 难度 · 收藏 |
| 好词好句 | 全部 / 句式 / 搭配 / 替换 / 用法 / 金句 | 主题（默认）· 形式 · 字母 · 收藏 |
| 范文解析 | 全部 / 考研英语一 / 考研英语二 / 雅思 / … | 年份（默认，倒序）· 考试 · 题型 · 主题 · 收藏 |

### 卡片样式

面板里第三组是「卡片」，三档，每个板块可以分别设置，存在 localStorage：

| 样式 | 卡片上显示 |
|---|---|
| **极简**（默认） | 只有英文本身。释义、例句、用法全部进详情页再看 |
| **标准** | 英文 + 一行中文 |
| **详细** | 完整信息：类型角标、英文释义、派生词预览、条目数 |

极简下卡片密度最高（1440px 宽时词根一行能排 8 张），星号悬停才浮现，触摸设备上常驻。

句库没有详情页，所以它的极简卡片是**点开揭示**——正面只有英文，点一下翻出中文和用法注解，正好当自测卡用。点星号或复制按钮不会触发翻卡。

首字母分组会自动剥掉后缀条目开头的连字符，`-able / -ible` 归入 **A**，`-tion` 归入 **T**。句库的「主题」和辨析的「类别」按数据文件里的出现顺序排列（不按拼音），所以你在 `data/phrases.js` 里怎么编排，页面上就是什么顺序。

**详情页**：每个部分都能单独折叠 —— 单词页是「核心图景 / 构词与词源 / 义项 / 边界与关联 / 一句话带走」，词根页是「每层含义各一节 + 相关词根 + 用到它的单词剖析」，辨析页是「一句话区分 / 逐词拆解 / 易错点 / 自测」，范文页是「题目 / 结构提纲 / 正文与批注 / 可迁移表达 / 一句话带走」。

折叠状态按**部分**记忆而不是按条目记忆：在某个单词页折叠了「核心图景」，之后打开任何一个单词都是折叠的（词根的义项节例外，它按「哪个词缀的第几层」单独记）。想只看派生词、只做自测、只读正文，设置一次就一直生效。排序方式和折叠状态都存在 localStorage，刷新和跨页都保留。

想加新的排序方式，改 `app.js` 里的 `SORTS` 对象：`group` 函数返回分组名，`order` 数组指定组的先后，`cmp` 决定组内排序。

## 小功能

- **⌘K / Ctrl+K** 聚焦搜索框。搜索覆盖全部五个板块，且分两层：
  - **卡片**（单词、词缀、辨析、句子、范文各自的条目）——除了正文，它自身的**分类信息也进索引**，所以可以直接搜「前缀」「后缀」「金句」「句式」「高频易错」「雅思」「Task 2」「教育」这类分类词，把整类卡片调出来。结果里带「卡片」徽标、边框更实。
  - **片段**（一层义项、一个派生词、一条可迁移表达）——搜具体内容时命中。
  - 同等匹配下**卡片排在片段之前**；结果顶部有按板块筛选的 chips（全部 / 单词剖析 / 词根词缀 / 关键辨析 / 好词好句 / 范文解析），带各自条数。
- **星号** 收藏任意条目，存在浏览器本地（localStorage），换设备不同步。
- **主题按钮** 在 跟随系统 → 浅色 → 深色 之间循环。
- **骰子按钮** 随机跳到一条词根／辨析／范文，用来做无目的的复习。
- **打印**：Ctrl+P 会自动隐藏导航栏，可以把某个词根或范文打成复习纸。

## 响应式

| 屏幕宽度 | 布局 | 词根卡片列数 |
|---|---|---|
| ≥ 1100px | 完整侧栏（220px）+ 卡片墙 | 5 |
| 760–1099px（平板） | 图标导轨（78px）+ 卡片墙 | 3 |
| 360–759px（手机） | 底部标签栏，安全区适配 | 2 |
| < 360px | 同上 | 1 |

## 本地预览

双击 `index.html` 即可。想用本地服务器（推荐，行为和线上一致）：

```bash
python -m http.server 5599
```

然后访问 http://localhost:5599

## 文件结构

```
index.html              页面骨架 + 图标 sprite
assets/css/styles.css   设计系统（令牌 → 基础 → 布局 → 导航 → 组件 → 板块 → 响应式）
assets/js/app.js        路由、视图渲染、搜索、收藏、主题、双向链接索引
data/words.js           单词剖析
data/roots.js           词根词缀
data/contrasts.js       关键辨析
data/phrases.js         好词好句
data/essays.js          范文解析
```

想加一个全新板块，在 `app.js` 顶部的 `SECTIONS` 数组里加一项，再写一个对应的 `VIEWS.你的板块名` 函数即可 —— 导航、配色、路由会自动接上。
